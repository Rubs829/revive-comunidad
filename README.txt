REVIVE COMUNIDAD - MAQUETA HTML/CSS/JS

Archivos principales:
- index.html
- styles.css
- script.js

La accesibilidad se integra directamente en el diseño. No se incluye una barra de botones para cambiar tamaño, contraste o movimiento.
La maqueta incorpora: HTML semántico, jerarquía de encabezados, contraste legible, foco visible, enlace para saltar al contenido, navegación por teclado, menú adaptable a móvil, etiquetas de formulario, diseño responsive y reducción de movimiento mediante las preferencias del sistema.

Para GitHub Pages:
1. Crea un repositorio público.
2. Sube index.html, styles.css y script.js directamente a la raíz del repositorio.
3. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta / (root).
4. Guarda y espera a que GitHub publique el sitio.
